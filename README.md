# チラシ拠点情報 差し込みツール

チラシ（PDF / JPG / PNG）に拠点名・TEL・FAX・担当者印・自由テキストを載せて、PNG / PDF で出力するブラウザツールです。

## 使い方

1. チラシのファイルをドロップ（またはタップして選択）
2. 拠点を選ぶ（表示名・TEL・FAXは編集可）
3. 位置を調整して PNG / PDF を出力

- PC：プレビュー上をドラッグで移動、矢印キーで微調整（Shiftで大きく）
- スマホ：要素の選択ボタン＋十字パッドで移動（押している間は連続移動）

## 特長

- インストール不要、ブラウザだけで動作（PC / スマホ対応）
- **処理はすべて端末内で完結**します。ファイルが外部に送信されることはありません
- 担当者印（シャチハタ風）、自由入力のもう一行、書体（角ゴ/丸ゴ）・色・サイズの調整に対応

## 拠点情報の更新

`index.html` 内の `OFFICES` 定数（「拠点マスタ」のコメント付近）を編集してください。

## 利用ライブラリ

- [pdf.js](https://mozilla.github.io/pdf.js/)（PDF表示）
- [pdf-lib](https://pdf-lib.js.org/)（PDF出力）

いずれもCDN（cdnjs）から読み込んでいます。
